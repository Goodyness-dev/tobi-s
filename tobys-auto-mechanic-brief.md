## Notes for Antigravity

- The quote wizard is the most important interactive element — it must work smoothly on mobile
- Geolocation on Step 9 should fail gracefully (if user denies permission, just show the empty text field)
- The wizard should show a progress bar or step counter so users know how far they are
- All 19 services use the same wizard flow — no service-specific branching except the engine sub-type question
- Photos: use placeholder images for now, make it easy to swap in real ones later
- No pricing listed — the wizard collects info so the shop can send back a custom quote
